# JRNY Experiential

Portfolio website for JRNY Experiential: events, MICE, exhibitions and experiential marketing across India and 18+ countries.

A static site with no build step. Open `index.html` in a browser, or deploy the folder to any static host (Netlify, GitHub Pages, Cloudflare Pages, Vercel).

## Pages

- `index.html`: main page with a pinned hero, the J-R-N-Y approach, expertise, 83 projects with galleries and video, the anamorphic/content showcase, reach, clients and contact.
- `exhibitions.html`: 11 pavilions and stands, with a scroll-driven floor plan.

## Folders

- `img/full/`, `img/thumb/`, `img/wide/`: project boards from the JRNY and ZDS decks (full size, card thumbnails, wide crops for the exhibitions page).
- `img/jrny-logo.svg`, `img/favicon.svg`: logo and favicon from the JRNY brand guideline V3.
- `vid/`: 40-second 720p highlights of 21 aftermovies, with poster frames. Full-length films are linked from the site on Google Drive.

## Brand

Follows the JRNY brand guideline V3: Helvetica Neue, orange `#ff5b00` on black, the guideline's line pattern and logo usage rules.
